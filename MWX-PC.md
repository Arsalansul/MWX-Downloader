# MWX PC

`mwx.py` запускает JSON-парсеры Manga Watcher X непосредственно на ПК. Требуется
Python 3.9+; внешние пакеты и Java не нужны. На Windows можно использовать
`mwx.cmd`: он сам найдёт команду `py` или `python`.

## Веб-интерфейс

На Windows запустите:

```powershell
.\mwx-web.cmd
```

Сервис выберет свободный порт, откроет браузер и будет доступен только с этого
компьютера по адресу `127.0.0.1`. На странице можно выбрать источник, загрузить
его каталог либо вставить прямую ссылку, открыть тайтл, отметить главы и поставить
их в очередь скачивания. Прогресс обновляется автоматически, результаты по
умолчанию сохраняются в `downloads` в формате CBZ.

Полезные параметры:

```powershell
.\mwx-web.cmd --port 8765
.\mwx-web.cmd --no-browser
.\mwx-web.cmd --no-cbz --output "D:\Manga"
```

Остановка сервиса: `Ctrl+C` в его окне. Статусы источников в списке взяты из
последнего `parser-check.json`; сайты со статусом «частично» иногда работают
только через прямую ссылку.

## Команды

Показать источники:

```powershell
.\mwx.cmd sources
```

Проверить все источники минимальными запросами и получить отчёт:

```powershell
.\mwx.cmd check
```

Результат сохраняется в `parser-check.json` и `parser-check.md`. Проверка одного
источника: `.\mwx.cmd check --parser mangabuff`. Массовая проверка намеренно не
отправляет встроенные в JSON cookies, bearer-токены и API-ключи.

Получить каталог и полные метаданные всех его тайтлов в `mwx.sqlite`:

```powershell
.\mwx.cmd meta --parser manga24
```

Получить метаданные одного тайтла в консоль или JSON-файл:

```powershell
.\mwx.cmd info --parser mangabuff --url "https://mangabuff.ru/manga/rycar-zhivushchii-odnim-dnem"
.\mwx.cmd info --parser mangabuff --url "https://mangabuff.ru/manga/rycar-zhivushchii-odnim-dnem" --output title.json
```

Получить только краткий каталог, не открывая каждый тайтл:

```powershell
.\mwx.cmd meta --parser manga24 --no-full
```

Обойти все источники:

```powershell
.\mwx.cmd meta --all
```

Операции скачивания принимают один `--parser`, поэтому разные источники можно
запускать последовательно, с отдельной командой для каждого. Это также не даёт
случайно начать загрузку всего содержимого всех 78 источников одной опечаткой.

Для безопасной первой проверки ограничьте каталог двумя страницами:

```powershell
.\mwx.cmd meta --parser manga24 --full --max-pages 2
```

Количество тайтлов также можно ограничить: `--max-titles 3`.

Скачать конкретную главу:

```powershell
.\mwx.cmd chapter --parser manga24 --url "https://manga24.ru/fairytail/001" --series "Fairy Tail" --name "Глава 1"
```

Можно вставить ссылку и в Markdown-виде `[адрес](адрес)` — CLI автоматически
извлечёт из неё настоящий URL. Обычный URL всё же нагляднее и предпочтительнее.

Скачать все главы тайтла:

```powershell
.\mwx.cmd title --parser manga24 --url "https://manga24.ru/fairytail"
```

Проверить загрузку только одной главы тайтла можно через `--max-chapters 1`.

Скачать все главы всех тайтлов источника:

```powershell
.\mwx.cmd all-titles --parser manga24
```

Для пробного массового запуска используйте вместе `--max-pages 1
--max-titles 1 --max-chapters 1`.

По умолчанию каждая глава сохраняется как CBZ и как папка с изображениями.
Отключить CBZ можно ключом `--no-cbz`. Повторный запуск пропускает уже загруженные
непустые изображения. `--workers 1` снижает нагрузку на сайт, а `--delay 2`
добавляет двухсекундную паузу между запросами страниц каталога и глав.

## Ограничения

Формат MWX накопил много специальных расширений. Реализованы распространённые
правила `iterator`, `get_string`, `get_array`, `add_manga`, `add_chapter`,
`add_images`/`add_pages`, замены, заголовки и cookies. Источники с авторизацией,
JavaScript-защитой, отдельным API-итератором или вычисляемым списком глав могут
потребовать небольшой адаптер. CLI завершает такую операцию явной ошибкой и при
массовом обходе продолжает со следующим тайтлом/источником.

Скачивайте только материалы, к которым у вас есть законный доступ, и соблюдайте
правила и ограничения конкретного сайта.
